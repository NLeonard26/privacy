Privacy Policy

App: Rangka Lab Automation (shown on Google sign-in as "n8n")
Last updated: October 2, 2026

What this app is

This is a private automation used only by its owner. It runs on the owner's own computer (a self-hosted n8n instance) and is not offered to the public.

What data it accesses

When the owner signs in with Google, the app may access the owner's own:

  • Google Sheets: to read and add rows in the owner's video log spreadsheet.
  • Google Drive: to upload video files to the owner's Drive and create share links for them.
  • YouTube: to upload videos to the owner's YouTube channel.

How data is used and stored

  • Data is used only to run the owner's automation described above.
  • Sign-in tokens are stored only in the owner's self-hosted n8n instance.
  • No data is sold, shared with third parties, or used for advertising.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
